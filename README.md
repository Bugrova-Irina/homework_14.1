# Ядро для интернет-магазина

## Описание:

Созданы классы Product и Category. Для классов описаны необходимые атрибуты.
Созданы дочерние классы Smartphone и LawnGrass от класса Product, которые определяют 
две категории товаров: "Смартфон" и "Газонная трава".

## Требования к окружению:

Установите:
 - python 3.13.0
 - Poetry
 - Pytest
 - pytest-cov

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/Bugrova-Irina/coursework_1/
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
```
poetry add --group dev pytest
```
```
poetry add --group dev pytest-cov
```
## Использование:

Использование классов предполагается в процессе разработки ядра будущего интернет-магазина.

## Тестирование:
В папке tests для модулей созданы тесты. Проверяется корректность инициализации объектов классов 
Category, Product, Smartphone, LawnGrass, корректность подсчета категорий и продуктов.
Тестирование выполняется командой pytest в терминале.
