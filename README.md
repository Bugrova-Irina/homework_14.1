# Ядро для интернет-магазина

## Описание:

Созданы классы Product и Category. Для классов описаны необходимые атрибуты.
Созданы дочерние классы Smartphone и LawnGrass от класса Product, которые определяют 
две категории товаров: "Смартфон" и "Газонная трава". Создан базовый абстрактный класс  
BaseProduct, который стал родительским для класса продуктов. Классы Smartphone и LawnGrass
остались наследниками класса Product. Создан класс PrintMixin, который при создании объекта 
печатает в консоль информацию о том, от какого класса и с какими параметрами был создан объект.

## Требования к окружению:

Установите:
 - python 3.13.0
 - Poetry
 - Pytest
 - pytest-cov

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/Bugrova-Irina/homework_14.1/
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
```
poetry add --group dev pytest
```
```
poetry add --group dev pytest-cov
```
## Использование:

Использование классов предполагается в процессе разработки ядра будущего интернет-магазина.

## Тестирование:
В папке tests для модулей созданы тесты. Проверяется корректность инициализации объектов классов 
Category, Product, Smartphone, LawnGrass, корректность подсчета категорий и продуктов 
(test_category.py, test_products.py, test_smartphone.py, test_lawngrass.py). Проверяется 
корректность вывода в консоль информации о том, от какого класса и с какими параметрами был создан
объект(test_print_mixin.py).
Тестирование выполняется командой pytest в терминале.
